change_file_name.py -> เปลี่ยนชื่อไฟล์ เป็นรูปแบบ {subject}_{activity}_{n} โดยมันจะตัด meta data ด้านหลังชื่อที่มาจากการบันทึก phyphox
config.py -> ตั้งค่าสำหรับตัวแปร global ใช้งานร่วมกันทุกไฟล์ 
merge.py -> รวมไฟล์จากรูปแบบ {subject}_{activity}_{n} เป็น ไฟล์เดียวและสร้างเป็นโฟลเดอร์ ที่ชื่อ {subject}_{activity} เพื่อนำข้อมูลที่ตัดและรวมมาเพื่อเป็นข้อมูลสำหรับการสร้างไฟล์ data ที่ใช้เทรน activity
features_mader.py -> นำข้อมูลจากโฟลเดอร์ data ซึ่งในนั้นมีข้อมูลกดิบของแต่ละคนมาคำนวณสร้าง features 24 ตัว เพื่อใช้เป็นข้อมูลสำหรับการสร้าง ai และสร้างไฟล์ ที่ชื่อว่า features_ready.csv
